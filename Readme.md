# My LangChain Learning Journey

This repository is where I’m learning LangChain by building small Python examples and experimenting with its core concepts. Rather than one finished application, it is a collection of notes and hands-on exercises that show how the pieces of an LLM application fit together.

I’m exploring how to give a model instructions, connect it to prompts and conversation history, and then compose it with other steps to build more useful workflows. I’m also learning how to work with different chat models, represent text as embeddings, and control the shape of a model’s output.

## What I’m learning

- **Chat models:** Calling models from providers such as Google Gemini, Anthropic, Hugging Face, and Ollama.
- **Prompts and messages:** Creating prompt templates, formatting conversations, and keeping chat history with message placeholders.
- **Chains:** Combining model and prompt steps into simple, sequential, parallel, multi-step, and conditional workflows.
- **Runnables:** Composing LangChain operations into sequences, passing values through workflows, and branching based on input.
- **Embeddings:** Turning text and documents into vectors, and comparing those vectors to find relevant content.
- **Structured output and parsers:** Asking models for data in defined formats, including JSON schemas and Pydantic models, and parsing string or JSON responses.
